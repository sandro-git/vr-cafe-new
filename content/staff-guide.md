# Documentation opérationnelle VR Café

## Mise en route quotidienne (ouverture)

### Partie filaire (rez-de-chaussée)
1. Allumer le PC serveur
2. Ouvrir l'application Octopod
3. Aller dans Configuration
4. Allumer les machines
5. Une fois toutes les machines allumées, lancer Arvi VR
6. Cliquer sur "Stations" et démarrer SteamVR
7. Une fois SteamVR lancé sur toutes les stations, aller sur chacune d'elles via le bouton VNC
8. Lancer Discord et se mettre sur le channel vocal 1

### Partie sans fil (étage)
1. Allumer tous les casques Focus 3
2. Allumer le PC serveur "haut"
